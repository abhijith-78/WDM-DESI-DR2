# Modified CAMB

The modified version of **CAMB** used for this analysis is maintained in a separate repository:

**[Modified CAMB repository](https://github.com/abhijith-78/CAMB_DDM)**

The modifications implement the non-cold/dynamical dark matter model used in:

> U. Kumar, A. Ajith and A. Verma, *"Cosmological constraints on non-cold dark matter from DESI DR2 measurements."*
